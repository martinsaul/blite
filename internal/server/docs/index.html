Bellion Share documentation

Bellion Share (formerly Blite) is peer-to-peer group screen sharing for Windows and Linux. Everyone in a room can share a screen, a window and app audio at the same time. The server only introduces people to each other; your video goes straight to your friends.

Open source

Bellion Share is a vibecoded application: it was built with AI coding agents. It is fully open source and free: you pay nothing to use it. You are not only allowed but encouraged to review the code base yourself, or to have AI agents review it for you.

Bellion Share is free software under the GNU Affero General Public License v3.0. The source code is on GitHub; the code, binaries and packages still use the old blite name.
